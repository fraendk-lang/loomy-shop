# Loomy – Landingpage & Shop (Entwurf)

Landingpage mit Shop-Bereich für **Loomy**, handgestrickte Strickmode aus dem Punjab, Indien (India Capsule W26).

- `index.html` – Seite (HTML + CSS)
- `shop.js` – Produktdaten, Filter, Farbvarianten, Warenkorb
- `img/` – Produktfotos (Platzhalter aus dem Lookbook) und Logo

**Status:** Design-Entwurf. Preise, Versand, Größen und Texte in eckigen Klammern sind Platzhalter. Die Kasse ist noch nicht angebunden.

Neue Produkte werden in `shop.js` im Array `PRODUCTS` ergänzt.
